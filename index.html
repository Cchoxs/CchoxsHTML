01 — FUNDAMENTOS

O que é HTML?

HTML é a linguagem que organiza o conteúdo de uma página web.

🧱

Estrutura

Organiza textos, imagens, links, botões e outros elementos.

🏷️

Elementos

Tags informam ao navegador o papel de cada parte do conteúdo.

🌐

Navegador

Interpreta o HTML e transforma seu código em uma página visual.

02 — TECNOLOGIAS

HTML, CSS e JavaScript.

Cada tecnologia possui uma função diferente na criação de sites.

🏗️

HTML

Estrutura e conteúdo. O esqueleto da página.

🎨

CSS

Aparência, layout, cores, transições e animações.

⚡

JavaScript

Interação e comportamento dos elementos.

03 — ESTRUTURA

A anatomia de uma página.

Pense no HTML como uma árvore: elementos maiores possuem elementos dentro deles.

📄 <html>
├── <head>
├── <title>
└── </head>
├── <body>
├── <h1>
├── <p>
└── </body>
└── </html>

🧠 Entenda a hierarquia

O <html> contém toda a página. O <head> guarda informações sobre o documento. O <body> contém o conteúdo que aparece para o usuário.
